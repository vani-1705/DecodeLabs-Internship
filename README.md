# 🌐 DecodeLabs Internship - Frontend Projects

This repository contains frontend development tasks completed as part of the DecodeLabs Internship program.  
All projects are built using **HTML5 and CSS3** focusing on strong frontend fundamentals, clean UI structure, and semantic web design.

---

# 📌 Task 1: Static Webpage Designing Using HTML & CSS 

📄 As per Task 1 requirements, a static webpage had to be created using only HTML and CSS, focusing on proper structure, clean layout, and basic frontend fundamentals without using JavaScript or backend.

🌏 Based on these instructions, I developed the **Explore India** travel webpage using HTML and CSS.

🏞 It presents popular tourist destinations in India with a simple, structured, and visually clean design.

# 📌 Task 2: Responsive Web Layout Using HTML & CSS

📄 As per Task 2 requirements, a responsive webpage had to be developed using HTML and CSS, focusing on CSS Media Queries, responsive navigation, proper spacing, and layouts that adapt across different screen sizes. 

🍽️ Based on these instructions, I developed the Thali House responsive restaurant website using HTML and CSS.

🌏 It showcases authentic Indian regional thalis through a modern, mobile-friendly, and visually appealing user interface while ensuring a seamless experience across desktop, tablet, and mobile devices.
