# 📌 Project Overview

Thali House is a responsive restaurant-themed website designed to showcase India's diverse regional thalis through an attractive and modern user interface.

The website provides visitors with an engaging browsing experience featuring a food menu, interactive cart system, restaurant information, social media integration, and contact details.

This project was developed as part of a Frontend Development Internship using only HTML and CSS.
