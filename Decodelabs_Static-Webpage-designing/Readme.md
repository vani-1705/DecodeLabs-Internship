# 📌 Project Overview

Explore India is a modern travel-themed static webpage designed to present India's most popular tourist destinations, cultural richness, delicious food, historic heritage, festivals, and natural landscapes through an attractive user interface.

This project was developed as part of a Frontend Development Internship project using only HTML and CSS.

---

# ✨ Features

- Responsive webpage design
- Modern hero section
- Popular tourist destinations cards
- Why Visit India section
- Image gallery section
- Footer with social links
- Clean and readable UI
- Smooth layout and styling
- Mobile responsive design
